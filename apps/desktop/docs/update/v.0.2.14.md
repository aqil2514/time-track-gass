- Tambah halaman reset password
- Tambah alur reset password 2 langkah
- Perbaiki tombol Forgot Password agar mengarah ke halaman reset password

## Fitur Reset Password
- User dapat membuka halaman reset password dari tombol Forgot Password pada form login
- Step 1: user memasukkan username atau email untuk verifikasi akun
- Step 2: jika akun memang wajib reset password, user dapat mengatur password baru
- Validasi password mengikuti aturan yang sama seperti halaman register
- Setelah reset berhasil, user diarahkan kembali ke halaman login dengan pesan sukses
