# Login

Halaman login adalah pintu masuk ke aplikasi. Kamu perlu login terlebih dahulu sebelum bisa menggunakan fitur apapun.

## Cara login

1. Buka aplikasi Time Track di komputermu
2. Masukkan **username atau email** pada kolom pertama
3. Masukkan **password** pada kolom kedua
4. Klik tombol **Sign In**

Tombol Sign In hanya aktif setelah kedua kolom terisi.

## Pesan error yang mungkin muncul

| Pesan | Artinya |
|---|---|
| Account not found | Username atau email tidak terdaftar |
| Invalid password | Password yang dimasukkan salah |
| Network error. Check your internet connection. | Aplikasi tidak bisa terhubung ke server — pastikan koneksi internet aktif |
| Server error. Please try again later. | Ada gangguan di server — coba beberapa saat lagi |

## Belum punya akun?

Klik **Create account** di bagian bawah halaman login untuk membuat akun baru.

## Catatan

- Jika akunmu sedang dalam status reset password (diatur oleh admin), kamu tidak bisa login langsung. Kamu perlu mengatur password baru terlebih dahulu melalui halaman **Reset Password**.
- Jika sudah login sebelumnya dan sesi masih aktif, aplikasi akan langsung membawamu ke halaman utama tanpa perlu login ulang.
