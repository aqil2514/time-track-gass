# Instalasi Aplikasi

Halaman ini menjelaskan cara mengunduh dan memasang aplikasi Time Track di komputermu.

---

## Persyaratan sistem

Aplikasi ini tersedia untuk:

- **Windows** — Windows 10 atau lebih baru
- **macOS** — macOS 10.15 (Catalina) atau lebih baru

---

## Cara menginstal

### Windows

1. Unduh file installer berekstensi `.exe` yang diberikan oleh admin atau supervisormu
2. Jalankan file tersebut
3. Ikuti langkah-langkah instalasi yang muncul di layar
4. Setelah selesai, aplikasi **Time Track** akan tersedia di Start Menu atau Desktop

### macOS

Pastikan kamu mengunduh versi yang sesuai dengan chip Mac-mu:

| Tipe Mac | File yang diunduh |
|---|---|
| Mac M1 / M2 / M3 / M4 (Apple Silicon) | `time-track_aarch64.app.tar.gz` |
| Mac Intel | `time-track_x64.app.tar.gz` |

Tidak yakin chip apa yang dipakai? Klik ikon Apple () di pojok kiri atas → **About This Mac**. Jika tertulis **Apple M1** (atau M2/M3/M4), pilih versi aarch64. Jika tertulis **Intel**, pilih versi x64.

Setelah mengunduh file yang sesuai:

1. Ekstrak file `.tar.gz` — klik dua kali untuk membukanya secara otomatis
2. Seret ikon **time-track** ke folder **Applications**
3. Buka aplikasi dari Launchpad atau folder Applications

> Jika muncul peringatan "aplikasi tidak dikenali" di macOS, buka **System Settings > Privacy & Security** dan klik **Open Anyway**.

---

## Izin yang diperlukan (macOS)

Di macOS, aplikasi memerlukan izin **Screen Recording** untuk bisa mengambil screenshot layar secara otomatis.

Saat pertama kali dijalankan, sistem akan meminta izin ini. Jika tidak muncul:

1. Buka **System Settings > Privacy & Security > Screen Recording**
2. Pastikan **Time Track** ada dalam daftar dan dalam kondisi aktif

Tanpa izin ini, fitur tracker otomatis tidak akan berfungsi.

---

## Pembaruan aplikasi

Aplikasi akan memeriksa pembaruan secara otomatis setiap kali dibuka. Jika ada versi baru yang tersedia, akan muncul dialog konfirmasi:

> *"Versi baru X.X.X tersedia. Update sekarang?"*

Klik **Yes** untuk mengunduh dan memasang pembaruan. Aplikasi akan restart setelah proses selesai. Jika kamu memilih **No**, pembaruan bisa dilakukan di lain waktu saat aplikasi dibuka kembali.

---

## Langkah selanjutnya

Setelah aplikasi terpasang, buka aplikasi dan lanjutkan ke halaman **Login** untuk masuk ke akunmu — atau **Register** jika belum memiliki akun.
