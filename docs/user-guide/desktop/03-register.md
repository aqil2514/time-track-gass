# Register

Halaman register digunakan untuk membuat akun baru. Akses halaman ini melalui tombol **Create account** di halaman login.

## Cara mendaftar

1. Isi semua kolom yang tersedia:
   - **Full Name** — nama lengkapmu
   - **Username** — nama pengguna unik untuk login
   - **Email** — alamat email aktif
   - **Divisi** — pilih divisi tempatmu bertugas dari daftar yang tersedia
   - **Password** — buat password yang kuat
   - **Confirm Password** — ulangi password yang sama
2. Klik tombol **Create Account**
3. Jika berhasil, kamu akan diarahkan ke halaman login dengan pesan konfirmasi

## Ketentuan pengisian

**Username**
- Minimal 3 karakter, maksimal 30 karakter
- Hanya boleh mengandung huruf, angka, dan underscore (`_`)
- Tidak boleh sama dengan username yang sudah terdaftar

**Email**
- Harus berformat email yang valid
- Tidak boleh sama dengan email yang sudah terdaftar

**Password**
- Minimal 8 karakter
- Harus mengandung minimal satu huruf kapital
- Harus mengandung minimal satu angka

Indikator syarat password akan muncul otomatis saat kamu mulai mengetik password, menampilkan mana saja syarat yang sudah terpenuhi.

**Confirm Password**
- Harus sama persis dengan password yang dimasukkan

**Divisi**
- Wajib dipilih — daftar divisi disediakan oleh sistem

## Pesan error yang mungkin muncul

| Pesan | Artinya |
|---|---|
| Username already exists | Username sudah dipakai akun lain |
| Email already exists | Email sudah dipakai akun lain |
| Passwords do not match | Confirm password tidak cocok dengan password |
| Network error. Check your internet connection. | Koneksi ke server gagal |
| Server error. Please try again later. | Ada gangguan di server |

## Sudah punya akun?

Klik **Sign in** di bagian bawah halaman untuk kembali ke halaman login.
