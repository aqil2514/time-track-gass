# Reset Password

Halaman ini digunakan untuk mengatur ulang password akunmu.

## Penting untuk diketahui

Fitur reset password di aplikasi ini **tidak seperti "lupa password" pada umumnya**. Kamu tidak bisa meminta reset password sendiri kapan saja.

Reset password hanya bisa dilakukan jika **admin atau atasanmu sudah mengaktifkan izin reset** untuk akunmu terlebih dahulu. Jika belum diaktifkan, proses ini tidak akan bisa dilanjutkan.

Jika kamu memang lupa password dan belum mendapat izin reset, hubungi admin atau atasanmu untuk meminta akses reset password.

---

## Cara reset password

Prosesnya terdiri dari dua langkah dalam satu halaman.

### Langkah 1 — Verifikasi akun

1. Masukkan **username atau email** akunmu
2. Klik tombol **Continue**
3. Sistem akan mengecek apakah akunmu sudah mendapat izin reset password
4. Jika berhasil, halaman akan beralih ke langkah berikutnya

### Langkah 2 — Buat password baru

1. Masukkan **password baru** yang ingin digunakan
2. Masukkan ulang password yang sama pada kolom **Confirm Password**
3. Klik tombol **Reset Password**
4. Jika berhasil, kamu akan diarahkan ke halaman login

Setelah password berhasil diubah, kamu bisa langsung login menggunakan password baru tersebut.

---

## Ketentuan password baru

- Minimal 8 karakter
- Harus mengandung minimal satu huruf kapital
- Harus mengandung minimal satu angka

Indikator syarat password akan muncul otomatis saat kamu mulai mengetik, termasuk konfirmasi apakah kedua password sudah cocok.

---

## Pesan error yang mungkin muncul

| Pesan | Artinya |
|---|---|
| Account not found | Username atau email tidak terdaftar |
| Password reset is not available | Akunmu belum mendapat izin reset password dari admin |
| Passwords do not match | Password baru dan konfirmasi tidak sama |
| Network error. Check your internet connection. | Koneksi ke server gagal |
| Server error. Please try again later. | Ada gangguan di server |
